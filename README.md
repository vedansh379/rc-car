# rc-car
rc car enabled with buletooth 

Bluetooth controlled RC car using Arduino Nano and L298N motor driver.

## Components
- Arduino Nano
- HC-05 Bluetooth Module
- L298N Motor Driver
- 2 DC Gear Motors
- 18650 Battery

## Features
- Forward
- Backward
- Left/Right Turning
- Bluetooth Control

## Future Plans
- Obstacle Avoidance
- AI Tracking
